Это мой простой консольный менеджер задач, написанный на Python.

Я сделал его для себя, чтобы потренироваться с классами и работой с файлами, ну и чтобы можно было быстро набросать список дел прямо из терминала. Задачи сохраняются прямо в текстовый файл, так что никуда не пропадут после закрытия программы.


## Что тут есть:

**Добавление задач** — можно накидывать дела пачкой, а по окончании просто написать `стоп`, чтобы вернуться в меню.
**Просмотр** — выводит все актуальные задачи с нормальной нумерацией и заглавными буквами.
**Удаление по ключевому слову** — вводишь слово, и программа сама находит и вычищает нужную строчку (регистр ей не важен).
**Защита от дурака** — если ввести букву вместо цифры в меню, прога не упадет с ошибкой, а просто попросит повторить ввод.


## Как запустить:

Никаких сторонних библиотек устанавливать не нужно — всё работает на чистом Python (я запускал на 3.11).

1. Скачай файл с кодом.
2. Открой терминал в этой папке.
3. Запусти командой:
```bash
python main.py

```

*(Файл `todo.txt` создастся автоматически рядом со скриптом при первом добавлении задачи).*
